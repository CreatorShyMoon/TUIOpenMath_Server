# SysOpenMath — Полный патчноут и отчёт об изменениях

## 1. Концепция: от чего к чему пришли

| Компонент / Характеристика | Исходное состояние | Итоговое состояние |
| :--- | :--- | :--- |
| **Архитектура системы** | Монолитный TUI-клиент на C11/ncurses со статическими профилями | Распределённая клиент-серверная среда (FastAPI-репозиторий + C11 TUI-клиент) |
| **Сетевая автономность** | Жесткая зависимость от внешнего интернета; сбои при офлайн-работе | Полноценный автономный (Air-Gapped) режим с локальным PEP 503 PyPI и хранилищем артефактов |
| **Профили окружений** | Захардкожены в бинарнике; добавление требовало перекомпиляции | Динамические JSON-профили: загрузка с сервера, кэширование в `state/remote_profiles/` |
| **Доставка Python-пакетов** | Прямой `pip install` из PyPI (минуты скачивания, риск несовместимости) | Локальный индекс колес (wheels) на сервере; установка на скорости ~120–150 МБ/с |
| **Установка Julia LTS** | Падение с ошибкой при отсутствии системного бинарника `julia` | Автоматическая загрузка архива с локального сервера, проверка SHA-256 и распаковка |
| **Отрисовка и стабильность TUI** | Тряска, флуд логами и зависание при изменении размера; исчезновение статус-бара | Мгновенная плавная адаптация без мерцания (`resize_term`), статус-бар зафиксирован |
| **Управление сервером** | Ошибки `Address already in use (Errno 98)` из-за зависших процессов | Автоматическое освобождение порта 8000, команды `make server` и `make server-stop` |

## 2. Реализованные модули и подсистемы

### 2.1. Сервер локального репозитория (`server/`)
* **REST API на базе FastAPI (`server/app.py`):**
  * `GET /api/v1/health` — мониторинг доступности и диагностика состояния хранилища.
  * `GET /api/v1/profiles` — выдача каталога доступных математических профилей.
  * `GET /api/v1/artifacts` и `GET /artifacts/{category}/{filename}` — отдача бинарных архивов (Julia LTS) с динамической генерацией заголовка `X-Checksum-SHA256` и эндпоинтом `.sha256`.
  * `GET /simple/` и `GET /simple/{package}/` — полноценный PEP 503 PyPI Simple-индекс для автономной установки через стандартный `pip`.
* **Утилита зеркалирования (`server/mirror.py`):**
  * `sync all` (или `make mirror-all` / `make mirror-sync`) — комплексное скачивание ВСЕХ компонентов: Julia LTS, Scilab, Octave, ядер Jupyter и колёс (wheels) для всех 7 профилей.
  * `make mirror-octave` — скачивание дистрибутива GNU Octave (AppImage / portable tarball).
  * `make mirror-scilab` — скачивание переносимого дистрибутива Scilab x86_64 (официальный standalone .tar.gz с зеркал UTC/Scilab.org либо реальные бинарные пакеты `scilab-cli` + `scilab-data`; автоматическое удаление пустых метапакетов `0.0 MB`).
  * `make mirror-julia` — скачивание дистрибутива Julia LTS.
  * `make mirror-runtime` — кэширование пакетов JupyterLab и всех ядер (`bash_kernel`, `octave_kernel`, `scilab_kernel`, `ipykernel`).
  * `make bundle` — автоматическая сборка единого переносимого архива `sysopenmath-monolith-offline.tar.gz`.
  * Валидация целостности архивов (`gzip test`) перед сохранением для предотвращения битых файлов.
  * Безопасное скачивание во временный файл (`.tmp`) с атомарной заменой.
* **Управление процессами сервера (`server/start.sh`, `Makefile`):**
  * Многоступенчатая очистка зависших процессов uvicorn через `pkill -9`, `fuser`, `lsof`, `ss`.
  * Предварительная проверка сокета на доступность порта перед запуском.
  * Команда `make server-stop` для гарантированной остановки.

### 2.2. Клиентская часть (C11, TUI)
* **Динамическая конфигурация (`include/client_config.h`, `src/client_config.c`):**
  * Загрузка и сохранение настроек из `config/client.json` (URL сервера, таймауты, флаг `offline_mode`).
* **Нативный парсинг профилей через `cJSON` (`src/profiles.c`):**
  * Устранение вызова Python-однострочников из bash (ликвидированы ошибки экранирования кавычек и `SyntaxError`).
  * Распаковка JSON-ответа сервера напрямую в `state/remote_profiles/*.json` с нативным тегированием `[сервер]`.
* **Автоматическое управление Julia LTS (`src/install_steps.c`, `src/julia_manager.c`):**
  * Скачивание архива с локального сервера артефактов при отсутствии бинарника.
  * Проверка контрольной суммы SHA-256.
  * Проверка целостности архива `tar -tzf` перед распаковкой с выводом понятных рекомендаций при сбоях.
  * Увеличен сетевой таймаут `curl` до 300 секунд для надежной передачи больших файлов.
* **Переключение режима Онлайн / Офлайн:**
  * Горячая клавиша `O` или выбор в меню «Репозиторий».
  * В офлайн-режиме pip автоматически перенаправляется на локальный индекс (`--index-url http://127.0.0.1:8000/simple/ --trusted-host 127.0.0.1`).

## 3. Исправление критических дефектов интерфейса

1. **Устранение бесконечного шторма `KEY_RESIZE`:**
   * Библиотечная функция `resizeterm()` заменена на `resize_term()`, исключившая повторное вбрасывание события `KEY_RESIZE` в очередь ввода `getch()`.
   * Добавлен сброс дубликатов событий (debounce) и проверка изменения фактического размера экрана через `ioctl(TIOCGWINSZ)`.
   * Удалено логирование изменения размера окна на каждый пиксель, исключившее дисковый I/O-флуд и перерисовку лога на 60 Гц.
2. **Ликвидация мерцания экрана:**
   * Удалены деструктивные вызовы `clear()` и `refresh()`.
   * Отрисовка переведена на фоновое обновление буферов (`wnoutrefresh`) с последующим атомарным сбросом на экран через `doupdate()`.
3. **Фиксация нижней статусной панели:**
   * В функции `draw_status()` длина выводимого текста ограничена `term_w - 1`. Это предотвратило аппаратный перенос каретки эмулятором терминала в угловой ячейке `(LINES-1, COLS-1)`, вызывавший скролл экрана вверх и исчезновение статус-бара в полноэкранном режиме.
4. **Устранение синтаксической ошибки bash (код 2) и ошибки mkstemp при полной подготовке профиля (Full Setup):**
   * Ранее `setup_build_full_profile_command` формировал гигантский сценарий как аргумент `bash -lc '...'`. Вложенные одинарные кавычки в `awk '{print $1}'` и `printf '...'` разрывали аргумент bash, приводя к синтаксической ошибке bash (exit code 2).
   * Функция переписана на безопасную атомарную генерацию скрипта `/tmp/sysopenmath_full_setup_XXXXXX` (устранён суффикс `.sh`, приводивший к `EINVAL` в `mkstemp` на Linux glibc) с `trap 'rm -f -- "$0"' EXIT`.
   * В `profile_config.c` и `setup_manager.c` реализован прямой поиск серверных профилей по `profile->path`, а также в каталогах `profiles/`, `state/remote_profiles/` и `server/storage/profiles/`. Все 7 серверных профилей протестированы и верифицированы.

## 4. Итоги тестирования

* **Офлайн-установка `remote-symbolic` и `remote-scientific`:** все 100+ зависимостей устанавливаются без выхода во внешнюю сеть.
* **Julia LTS:** архив скачивается, проверяется по SHA-256 и распаковывается без сбоев.
* **Интерфейс:** изменение геометрии терминала и переход в полный экран происходят мгновенно, без задержек и артефактов.
